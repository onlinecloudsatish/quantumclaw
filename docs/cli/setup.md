# `quantumclaw setup`

Initialize `~/.quantumclaw/quantumclaw.json` and the agent workspace.

Related:

- Getting started: [Getting started](/start/getting-started)
- CLI onboarding: [Onboarding (CLI)](/start/wizard)

## Examples

```bash
quantumclaw setup
quantumclaw setup --workspace ~/.quantumclaw/workspace
```

To run onboarding via setup:

```bash
quantumclaw setup --wizard
```
