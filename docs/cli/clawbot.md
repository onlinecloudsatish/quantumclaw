# `quantumclaw clawbot`

Legacy alias namespace kept for backwards compatibility.

Current supported alias:

- `quantumclaw clawbot qr` (same behavior as [`quantumclaw qr`](/cli/qr))

## Migration

Prefer modern top-level commands directly:

- `quantumclaw clawbot qr` -> `quantumclaw qr`
