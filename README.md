## What is QuantumClaw?

**QuantumClaw** is your personal AI assistant that runs on your own devices. It connects to your messaging platforms and helps you automate tasks, manage information, and interact with AI through natural conversation.

### Features

- **🤖 AI-Powered Assistant** — Smart conversations with context awareness
- **📱 Multi-Platform** — WhatsApp, Telegram, Slack, Discord, Signal, iMessage & more
- **⚡ Automation** — Workflows, scheduled tasks, webhook triggers
- **🧠 Memory** — Context-aware conversations with persistent memory
- **🔒 Security** — Input validation, encrypted secrets, audit logging
- **💻 Code Execution** — Run JavaScript/TypeScript in sandbox
- **🎨 Beautiful UI** — Modern dashboard with dark mode

## Requirements

- **Node.js**: v22.16+ or v24+ (recommended)
- **Runtime**: macOS, Linux, or Windows (WSL2)

## Quick Install

```bash
npm install -g quantumclaw@latest
```

## Getting Started

```bash
# Launch setup wizard
quantumclaw onboard --install-daemon

# Run the gateway
quantumclaw gateway --port 18789

# Send a message
quantumclaw message send --to +1234567890 --message "Hello!"

# Check status
quantumclaw status
```
